# StockFlow — Sistema de Gerenciamento de Produtos

Projeto acadêmico **independente do TCC/KoraMarketplace**, criado para demonstrar CRUD, layout, responsividade e versionamento.

## Objetivo
Desenvolver um sistema web para gerenciamento de produtos com **Cadastro, Consulta, Alteração e Exclusão**.

## Tecnologias
HTML5 • CSS3 • JavaScript • LocalStorage • Git/GitHub

## Funcionalidades
- Cadastro de produto
- Consulta e pesquisa
- Filtro por categoria
- Alteração
- Exclusão com confirmação
- Preço e estoque
- Imagem por URL
- Layout responsivo
- Menu mobile

## Como executar
Abra `index.html` no navegador ou use o Live Server do VS Code. Não precisa de banco de dados para a demonstração: os registros ficam no `localStorage`.

## Estrutura
```text
Projeto-CRUD-Produtos/
├── index.html
├── produtos.html
├── cadastro.html
├── css/style.css
├── js/app.js
├── img/
└── README.md
```

## CRUD
**Cadastro:** `cadastro.html` cria registros.  
**Consulta:** `produtos.html` lista, pesquisa e filtra.  
**Alteração:** botão Editar abre o formulário preenchido.  
**Exclusão:** botão Excluir remove após confirmação.
